# Qwen Enterprise RAG

A planned enterprise document assistant for uploading documents, semantic search, question answering, and source citations.

## Planned technology stack

- Python 3.11 or 3.12
- FastAPI backend
- Streamlit frontend
- Alibaba Cloud Qwen API
- A vector store for semantic retrieval

## Development status

Stage 1: project skeleton initialized. Application features and integrations are not implemented yet.

## Local initialization

1. Create and activate a virtual environment: `python3.11 -m venv .venv`.
2. Install the project when dependencies are added: `pip install -e .`.
3. Copy `.env.example` to `.env` and add your DashScope API key when API integration is implemented.

No third-party runtime dependencies are configured at this stage.
